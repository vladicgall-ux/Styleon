# STYLE ON — Telegram-бот школы стиля

Бот-меню для школы стиля **STYLE ON** (Челябинск) и курса «Персональный
стилист»: рассказывает о курсе, программе, тарифах и преподавателях,
собирает заявки на обучение. Построен на [aiogram 3](https://docs.aiogram.dev/).

## Возможности

- `/start`, `/menu` — приветствие и главное меню с разделами
- 🎓 О курсе, 🧵 Формат обучения, 📚 Программа (по месяцам/урокам)
- 💳 Тарифы (Слушатель / PRO / Индивидуально) с ценами и составом
- 👩‍🏫 Карточки преподавателей с фото
- 🏫 О школе, 💬 Отзывы выпускниц, ❓ FAQ (11 вопросов)
- 📝 Заявка на обучение прямо в боте (имя → контакт → тариф), которая
  пересылается в чат администратора; либо кнопка перехода в VK
- 💳 Оплата тарифа прямо в боте: реквизиты → «Я оплатил(а)» → ФИО → чек
  (фото/файл) → заявка уходит администратору с кнопкой «Подтвердить» →
  админ присылает ссылку на канал курса → клиент получает её автоматически
- 📊 `/stats` — админ видит, кто и какой тариф купил
- ⚙️ «Настройки контента» (видна только админу в главном меню, либо
  команда `/settings`) — редактирование текста и фото любого раздела
  прямо в боте, без изменения кода
- Ссылки на сообщество VK и сайт школы

Все тексты, цены, ссылки и фото собраны в одном месте — `bot/content.py`,
их легко поменять без изменения логики.

## Установка

1. Получите токен бота у [@BotFather](https://t.me/BotFather).
2. Установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и укажите токен:

   ```bash
   cp .env.example .env
   ```

   ```env
   BOT_TOKEN=123456:ВАШ_ТОКЕН
   ADMIN_CHAT_ID=ваш_telegram_id
   ```

   Чтобы узнать свой `chat_id` для `ADMIN_CHAT_ID`, напишите боту
   [@userinfobot](https://t.me/userinfobot). **`ADMIN_CHAT_ID` обязателен**
   для приёма заявок и оплат — без него кнопки «Оставить заявку» и
   «Подтвердить оплату» не будут доходить до вас.

4. Запустите бота:

   ```bash
   python main.py
   ```

## Структура проекта

```
main.py               # точка входа, запуск polling
bot/
  config.py            # чтение токена и ADMIN_CHAT_ID из .env
  content.py            # все тексты, цены, ссылки, пути к фото
  keyboards.py           # инлайн-клавиатуры меню
  media/                  # фотографии школы (курс, преподаватели, основатель)
  storage.py              # файловое хранилище заявок на оплату (data/orders.json)
  content_store.py        # хранилище правок текста/фото из /settings (data/content_overrides.json)
  handlers/
    start.py              # /start, /menu
    menu.py               # курс, формат, программа, тарифы, преподаватели, о школе, отзывы
    faq.py                # раздел частых вопросов
    apply.py              # сбор заявки (FSM) + пересылка администратору
    purchase.py           # оплата тарифа: реквизиты → ФИО → чек → отправка на проверку
    admin.py              # подтверждение оплаты, отправка ссылки на канал, /stats
    settings.py           # админ-панель: редактирование текста/фото разделов бота
```

## Настройки контента прямо из бота

Администратору (`ADMIN_CHAT_ID`) в главном меню видна дополнительная
кнопка «⚙️ Настройки контента» (или команда `/settings`). Там можно
выбрать любой раздел — приветствие, о курсе, формат обучения, о школе,
любого преподавателя, любой тариф, любой вопрос FAQ, отзывы — и:

- ✏️ заменить текст (можно с форматированием: жирный/курсив как в Telegram),
- 🖼 заменить фото (для разделов, где оно есть),
- ♻️ сбросить раздел обратно к исходному содержимому из `content.py`.

Правки хранятся в `data/content_overrides.json` и применяются сразу,
без перезапуска бота.

## Как работает оплата тарифа

1. Клиент на карточке тарифа нажимает «💳 Купить» → видит реквизиты
   для перевода (номер телефона, банк, получатель из `content.py`).
2. Нажимает «✅ Я оплатил(а)» → бот просит ФИО, затем чек (фото или файл).
3. После загрузки чека клиент нажимает «📤 Отправить заявку» — заявка
   со всеми данными и чеком уходит в чат администратора (`ADMIN_CHAT_ID`)
   с кнопкой «✅ Подтвердить оплату».
4. Администратор жмёт «Подтвердить», бот просит прислать ссылку на канал
   курса — админ присылает её текстом и подтверждает отправку кнопкой.
5. Клиент автоматически получает сообщение со ссылкой на канал.
6. Команда `/stats` (доступна только `ADMIN_CHAT_ID`) показывает, сколько
   и каких тарифов оплачено, и последние заявки.

Все заявки хранятся в `data/orders.json`, а правки контента — в
`data/content_overrides.json` (оба создаются автоматически, в git не
попадают). На части хостингов файловая система пересоздаётся заново при
каждом деплое — на Bothost для этого есть постоянное хранилище (Volume)
на тарифах Basic/Pro: в настройках проекта укажите точку монтирования на
папку `data/`, и все заявки и правки контента будут сохраняться между
деплоями и рестартами.

## Как изменить контент

Все данные школы — название, VK, сайт, дата старта потока, тексты о курсе,
программа по урокам, тарифы, преподаватели, отзывы, FAQ — находятся в
`bot/content.py`. Фотографии лежат в `bot/media/`; чтобы заменить фото,
положите новый файл с тем же именем (или поменяйте путь в `content.py`).

## Деплой

Для постоянной работы бота разверните `main.py` на сервере/VPS или в
любом окружении, поддерживающем долгоживущий процесс (например, через
`systemd`, `pm2`, Docker или сервис вроде Amvera/Railway), и держите файл
`.env` с токеном рядом — процесс должен работать непрерывно, чтобы бот
отвечал пользователям.

### Деплой на Bothost

Bothost нативно поддерживает aiogram 3.x, поэтому специальных изменений
в коде не требуется:

1. Зарегистрируйтесь на [bothost.ru](https://bothost.ru) и создайте новый
   проект для Telegram-бота на Python (aiogram 3.x).
2. Подключите этот GitHub-репозиторий и ветку `claude/telegram-school-bot-3tf8k5`
   (или залейте код архивом через веб-интерфейс) — `requirements.txt` и
   `Procfile` (`worker: python main.py`) в корне уже готовы к сборке.
3. В настройках проекта → «Переменные окружения» добавьте:
   - `BOT_TOKEN` — токен от @BotFather
   - `ADMIN_CHAT_ID` — (необязательно) chat_id для приёма заявок
   `.env`-файл заливать не нужно — Bothost передаёт эти переменные в
   процесс напрямую, а `bot/config.py` читает их через `os.getenv`.
4. Запустите деплой. Бот работает через long polling, поэтому вебхук
   и SSL настраивать не нужно — достаточно, чтобы процесс был запущен
   как воркер (`python main.py`).
5. При каждом пуше в подключённую ветку Bothost пересоберёт и
   перезапустит бота автоматически.
