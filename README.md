# STYLE ON — Telegram-бот школы стиля

Бот-меню для школы стиля **STYLE ON** (Челябинск) и курса «Персональный
стилист»: рассказывает о курсе, программе, тарифах и преподавателях,
собирает заявки на обучение. Построен на [aiogram 3](https://docs.aiogram.dev/).

## Возможности

- `/start`, `/menu` — приветствие и главное меню с разделами
- 🎓 О курсе, 🧵 Формат обучения, 📚 Программа (по месяцам/урокам)
- 💳 Тарифы (Слушатель / PRO / Индивидуально) с ценами и составом
- 👩‍🏫 Карточки преподавателей с фото
- 🏫 О школе, 💬 Отзывы выпускниц, ❓ FAQ (11 вопросов)
- 📝 Заявка на обучение прямо в боте (имя → контакт → тариф), которая
  пересылается в чат администратора; либо кнопка перехода в VK
- Ссылки на сообщество VK и сайт школы

Все тексты, цены, ссылки и фото собраны в одном месте — `bot/content.py`,
их легко поменять без изменения логики.

## Установка

1. Получите токен бота у [@BotFather](https://t.me/BotFather).
2. Установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и укажите токен:

   ```bash
   cp .env.example .env
   ```

   ```env
   BOT_TOKEN=123456:ВАШ_ТОКЕН
   ADMIN_CHAT_ID=  # необязательно — куда присылать заявки
   ```

   Чтобы узнать свой `chat_id` для `ADMIN_CHAT_ID`, напишите боту
   [@userinfobot](https://t.me/userinfobot).

4. Запустите бота:

   ```bash
   python main.py
   ```

## Структура проекта

```
main.py               # точка входа, запуск polling
bot/
  config.py            # чтение токена и ADMIN_CHAT_ID из .env
  content.py            # все тексты, цены, ссылки, пути к фото
  keyboards.py           # инлайн-клавиатуры меню
  media/                  # фотографии школы (курс, преподаватели, основатель)
  handlers/
    start.py              # /start, /menu
    menu.py               # курс, формат, программа, тарифы, преподаватели, о школе, отзывы
    faq.py                # раздел частых вопросов
    apply.py              # сбор заявки (FSM) + пересылка администратору
```

## Как изменить контент

Все данные школы — название, VK, сайт, дата старта потока, тексты о курсе,
программа по урокам, тарифы, преподаватели, отзывы, FAQ — находятся в
`bot/content.py`. Фотографии лежат в `bot/media/`; чтобы заменить фото,
положите новый файл с тем же именем (или поменяйте путь в `content.py`).

## Деплой

Для постоянной работы бота разверните `main.py` на сервере/VPS или в
любом окружении, поддерживающем долгоживущий процесс (например, через
`systemd`, `pm2`, Docker или сервис вроде Amvera/Railway), и держите файл
`.env` с токеном рядом — процесс должен работать непрерывно, чтобы бот
отвечал пользователям.
